# Users Mock API

Небольшой REST API на **FastAPI**, предназначенный для автоматизированного тестирования API и проверки соответствия OpenAPI-контракту.

## Что реализовано

- **REST API пользователей** — получение списка пользователей, получение пользователя по ID и создание нового пользователя.
- **Валидация данных** — проверка имени, email и возраста с помощью Pydantic.
- **Обработка ошибок** — ответы `404` для отсутствующего пользователя, `409` при дублировании email и `422` при ошибках валидации.
- **Детерминированные тестовые данные** — данные хранятся в памяти и сбрасываются при создании нового экземпляра приложения.
- **OpenAPI-спецификация** — генерация спецификации из приложения и сохранение её в `openapi.json`.
- **Проверка актуальности спецификации** — автоматический тест сравнивает OpenAPI-схему приложения с сохранённым файлом.
- **Генерация контрактных тестов** — Schemathesis генерирует запросы на основе OpenAPI и проверяет соответствие ответов контракту.

## Технологии

- Python
- FastAPI
- Pydantic
- pytest
- Schemathesis
- uv
- GitHub Actions

## Запуск

Установить зависимости:

```bash
uv sync --locked
```

Запустить тесты:

```bash
uv run --locked pytest -v
```

Сгенерировать актуальную OpenAPI-спецификацию:

```bash
uv run python -c "import json; from app.main import app; print(json.dumps(app.openapi(), indent=2))" > openapi.json
```

## CI

GitHub Actions автоматически запускает тесты при `push` и `pull_request`. Используется кеширование зависимостей `uv`, а результаты pytest сохраняются в виде JUnit XML и загружаются как артефакт `pytest-results` на 14 дней.

## Структура проекта

